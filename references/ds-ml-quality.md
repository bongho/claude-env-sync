# DS/ML 품질 규칙 (Data Science & ML Quality Rules)

## 데이터 품질

### 데이터 프로파일링 (필수 보고 항목)
- **null/결측치**: 비율, 패턴 (MCAR/MAR/MNAR)
- **카디널리티**: unique 값 수, high-cardinality 컬럼 식별
- **분포**: 히스토그램, 왜도/첨도, 이상치 (IQR/Z-score)
- **데이터 드리프트**: 학습 vs 서빙 분포 비교 (PSI, KL divergence)
- **데이터 타입**: 예상 타입 vs 실제 타입 일치 여부

### 데이터 무결성
- 중복 레코드 체크
- 참조 무결성 검증 (FK 관계)
- 시간순 정합성 (이벤트 로그)
- 단위/스케일 일관성

### 데이터 누수 방지
- train/test 분할: 시간 기반 split 우선 (미래 데이터 누수 방지)
- feature 생성: target 변수로부터의 역방향 누수 확인
- 전처리: train set에서 fit → test set에서 transform

## 실험 관리

### 실험 기록 (필수 항목)
- **가설**: 명확한 가설 문장
- **파라미터**: 모든 하이퍼파라미터 명시
- **메트릭**: 주요/보조 메트릭, 비즈니스 메트릭 연결
- **random_seed**: 재현성을 위한 시드 고정
- **데이터 버전**: 학습 데이터 스냅샷/해시
- **코드 버전**: git commit SHA

### 실험 비교
- Baseline 대비 성능 변화 (절대값 + 상대값)
- 통계적 유의성 검증 (t-test, bootstrap CI)
- 리소스 사용량: 학습 시간, GPU 메모리, 비용

## 모델 검증

### 오프라인 검증
- Hold-out / Cross-validation 결과
- 메트릭: 태스크별 적절한 메트릭 선택
  - 분류: AUC-ROC, F1, Precision/Recall (비즈니스 기준)
  - 회귀: RMSE, MAE, MAPE
  - 랭킹: nDCG, MAP, MRR
  - 추천: Hit Rate, Coverage, Diversity
- 과적합 체크: train vs validation 성능 갭
- 공정성 검증: 보호 속성별 성능 차이

### 온라인 검증
- A/B 테스트 설계: 표본 크기, 검정력, 실행 기간
- 가드레일 메트릭: 핵심 지표 하락 시 자동 롤백
- 점진적 배포: 1% → 10% → 50% → 100%

## 프로덕션 기준

### 배포 전 체크리스트
- [ ] 오프라인 메트릭 기준 충족
- [ ] 추론 지연시간 SLA 충족
- [ ] 메모리/CPU 사용량 허용 범위
- [ ] 입력 검증 로직 구현
- [ ] 모델 모니터링 설정 완료
- [ ] 롤백 절차 문서화
- [ ] 비용 추정 완료

### 모니터링 지표
- 예측 분포 드리프트
- 입력 데이터 드리프트
- 추론 지연시간 (p50, p99)
- 에러율, 타임아웃율
- 비즈니스 KPI 추적

## 노트북 → .py 전환 규칙
- 탐색 완료된 노트북 코드는 `.py` 모듈로 추출
- 함수/클래스로 구조화
- 단위 테스트 작성
- config는 외부 파일로 분리 (YAML/JSON)
- 매직 넘버 → 상수/설정값으로 변환
