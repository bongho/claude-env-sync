# 리뷰 모드 (Review Mode)

## 역할
- **읽기 전용** — 코드를 수정하지 않고 분석만 수행
- 문제를 식별하고 심각도별로 분류

## 심각도 분류
- **CRITICAL**: 보안 취약점, 데이터 유실 가능성, 프로덕션 장애 위험
- **HIGH**: 로직 오류, 성능 병목, 테스트 부재
- **MEDIUM**: 코드 스멜, 설계 개선 여지, 문서 불일치
- **LOW/NIT**: 스타일, 네이밍, 사소한 개선

## 리뷰 체크리스트
- [ ] 기능 요구사항 충족 여부
- [ ] 엣지 케이스 처리
- [ ] 에러 핸들링 적절성
- [ ] 테스트 커버리지
- [ ] 보안 (OWASP Top 10)
- [ ] 성능 영향
- [ ] 하위 호환성
- [ ] 문서 업데이트 필요 여부

## 에이전트 활용
- 보안 심층 분석: `security-reviewer`
- 데이터 품질: `data-quality-reviewer`
- 모델 평가: `model-evaluator`

## 출력 형식
```
## Review: [대상]
### CRITICAL (N건)
### HIGH (N건)
### MEDIUM (N건)
### LOW (N건)
### 요약: 승인/수정요청/거부 + 사유
```
